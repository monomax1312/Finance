# Финансовый трекер

Мини-банковский финансовый трекер с аналитикой по месяцам и категориям.

## Архитектура

Проект разделен на слои:

- `lib/data` — источники данных, DTO и реализации репозиториев
- `lib/domain` — сущности и бизнес-логика
- `lib/presentation` — UI, Bloc, маршрутизация и состояния

## Запуск

1. `flutter pub get`
2. `flutter run`

## Основные функции

- список операций (доходы и расходы)
- фильтр по месяцу и диапазону дат
- баланс, доход и расход
- статистика по категориям
